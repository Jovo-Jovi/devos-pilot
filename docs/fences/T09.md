- **S2 — Template splitter.** Create `src/content/template.ts` (no imports) exporting
  `export type TemplatePart = { kind: "text"; text: string } | { kind: "token"; name: string };` and
  `export function templateParts(template: string): TemplatePart[]`. It splits on `{name}` (name is

- **S3 — Pure time module.** Create `src/content/status.ts` (imports only the `OpeningSlot` type from
  `./schema`) exporting:
  ```ts
  export type CairoClock = { dayOfWeek: number; time: string }; // time is "HH:MM"
  export type OpenStatus =
    | { state: "open"; until: string }
    | { state: "closed"; opensDayOfWeek: number; opensAt: string }
    | { state: "none" };
  export function cairoClock(instant: Date): CairoClock;
  export function todaySlots(slots: readonly OpeningSlot[], dayOfWeek: number): OpeningSlot[];
  export function openStatus(slots: readonly OpeningSlot[], instant: Date): OpenStatus;
  ```
  - `cairoClock` uses `Intl.DateTimeFormat("en-US", { timeZone: "Africa/Cairo", weekday: "short",
    hour: "2-digit", minute: "2-digit", hourCycle: "h23" })` and `formatToParts`; map the weekday
    abbreviation to 0–6 (Sunday = 0) and zero-pad `HH:MM`. It never reads the runtime's local zone.
  - `todaySlots` returns that day's slots sorted by `opensAt` ascending, without mutating the input.
  - `openStatus`: `open` when some slot of Cairo today has `opensAt <= time < closesAt` (opening
    inclusive, closing exclusive), with `until = closesAt`. Otherwise `closed` with the next opening:
    first slot of today with `opensAt > time`, else the first slot of the following days, searching
    offsets 1 to 7 from today (offset 7 is the same weekday next week). `none` when `slots` is empty.
  - Names must pass `guard:naming` (`slot`, `slots`, `data`, `info`, `item`, `user` etc. are never
    bare type or field names).
