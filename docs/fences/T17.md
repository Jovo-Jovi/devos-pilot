### Prompt (canonical)

Staff at AAL2 see the week Saturday → Friday with each day's periods, and add, change and remove an
`OpeningSlot` (day, opens, closes, optional note pair). Each write invalidates the cache tag
`opening-slots`, so the home timetable, `StatusChip` and `TodayLine` on `/ar` and `/en` follow on the
next request without a rebuild, while the four public routes stay `○`. The browser never calls
Supabase; every write is a server action through `createStaffServerClient()`; RLS enforces the same
rule again (`opening_slots_*_staff`).

#### Steps

- **S1 — Input schema (`src/lib/supabase/opening-slot-input.ts`, pure, no `server-only`, `zod`).**
  - `OpeningSlotInput = { dayOfWeek: number; opensAt: string; closesAt: string; noteAr: string | null; noteEn: string | null }`;
    `OpeningSlotField` is the union of those five names; `OpeningSlotError = "required" | "time" | "order" | "pair"`.
  - `parseOpeningSlotInput(form: FormData)` returns `{ ok: true, value }` or
    `{ ok: false, fields: Partial<Record<OpeningSlotField, OpeningSlotError>> }`. Mirror DATA_MODEL §2.2:
    - `dayOfWeek`: exactly one of `"0"`…`"6"` → number; missing or anything else → `"required"`.
    - `opensAt`, `closesAt`: missing or `""` → `"required"`; else must match
      `^([01][0-9]|2[0-3]):[0-5][0-9]$` exactly, else `"time"`. Both valid and `opensAt >= closesAt`
      (plain string comparison, as `collate "C"`) → `closesAt: "order"`.
    - Notes: trimmed; blank → `null`. Exactly one non-null → the blank one gets `"pair"`.
  - `isOpeningSlotId(value: string): boolean` (the DATA_MODEL §2.2 kebab-case pattern);
    `parseHoursDone(value: unknown)` → `"added" | "changed" | "removed" | null`;
    `parseDayOfWeek(value: unknown)` → `0`…`6` from a string `"0"`…`"6"`, else `null`.
- **S2 — Server actions (`src/app/[locale]/staff/hours/actions.ts`, `"use server"`).**
  - `addOpeningSlot(locale, previous, formData)`, `changeOpeningSlot(locale, id, previous, formData)`
    → `Promise<OpeningSlotFormState>`; `removeOpeningSlot(locale, id, formData)` → `Promise<void>`.
  - Order in each: the locale check (as T16's `assertLocale`); `await requireStaff(locale)`; for
    change/remove `isOpeningSlotId(id)` (else `notFound()`); then the input schema (add/change); then
    the write. Columns: `day_of_week`, `opens_at`, `closes_at`, `note_ar`, `note_en`. Add inserts
    with no `id`; change updates the five columns `.eq("id", id)`; remove deletes `.eq("id", id)`.
    Every write ends `.select("id").maybeSingle()`; an error or no row is a failure.
  - Add/change: failure → `{ error: "save" }`; schema failure → `{ error: "invalid", fields }`.
    Remove: failure → `redirect("/{locale}/staff/hours?error=save")`.
  - After a successful write only: `updateTag("opening-slots")`, then redirect to
    `/{locale}/staff/hours?done=added|changed|removed`.
  - `OpeningSlotFormState = { error: "invalid" | "save" | null; fields?: … }`. Never log a value or an
    error body.
- **S3 — Pages (all: `StaffFrame` with the matching `path`, `Suspense`, `connection()` then
  `requireStaff(locale)` before any Supabase read; absolute `/${locale}/staff/hours…` links).**
  - `/[locale]/staff/hours` — `h1` `staff.hoursTitle`. Rows from `createStaffServerClient()`, mapped
    with `openingSlotsFromRows`, grouped with `timetableDays` (`src/content/timetable.ts`, Saturday →
    Friday). An `ol` of days; each day an `li` with an `h2` day name (`messages.days`), then a `ul` of
    periods — each `li`: times `<Bidi>{opensAt}–{closesAt}</Bidi>`, the note in the page locale if
    any, a link `staff.changeSlotLink` to `/{locale}/staff/hours/{id}`, and a one-button form
    (secondary button `staff.removeSlotSubmit`) bound to `removeOpeningSlot` — or `state.closed` in
    `--color-closed` when the day has none; then a link `staff.addSlotTitle` to
    `/{locale}/staff/hours/new?day={dayOfWeek}`. `?done=` (via `parseHoursDone`) shows
    `staff.confirmAdded|confirmChanged|confirmRemoved` with `role="status"` in `--color-open`;
    `?error=save` shows `staff.hoursErrorSave` with `role="status"` in `--color-stamp`.
  - `/[locale]/staff/hours/new` — `h1` `staff.addSlotTitle`; the form, day preselected from
    `parseDayOfWeek(searchParams.day)`, else `6`; a link `staff.backToHours`.
  - `/[locale]/staff/hours/[id]` — `h1` `staff.editSlotTitle`; invalid id or no row → `notFound()`;
    the form, prefilled; a link `staff.backToHours`.
  - The form (`src/app/[locale]/staff/OpeningSlotForm.tsx`, client, `useActionState`, `noValidate`):
    `dayOfWeek` (`select`, options Saturday → Friday from `TIMETABLE_DAY_ORDER` and `messages.days`),
    `opensAt`, `closesAt` (`type="time"`, each inside `Bidi` as T16's date control), `noteAr`
