- **S4 — `src/lib/r2/objects.ts`.**
  - `COVER_KEY_PATTERN`: the `object_key` regex of `DATA_MODEL.md` §10, character for character.
  - `coverPutInput(bucket: string, key: string, body: Uint8Array): PutObjectCommandInput` — throws
    `Error("invalid cover key")` unless `key` matches `COVER_KEY_PATTERN`; returns exactly
    `{ Bucket, Key, Body, ContentType: "image/webp", CacheControl }` with `CacheControl` equal to
    `public, max-age=31536000, immutable`, written as `` `public, max-age=${60 * 60 * 24 * 365}, immutable` ``
    (the literal digits trip `guard:literals`).
  - `putCoverObject(key: string, webp: Uint8Array): Promise<void>` — `PutObjectCommand(coverPutInput(...))`.
  - `deleteCoverObject(key: string): Promise<void>` — same key check, `DeleteObjectCommand`.
  - `coverPublicUrl(key: string): string` — `` `${r2PublicBaseUrl()}/${key}` ``.
- **S5 — `src/lib/r2/cover-image.ts`** (no S3 import):
  - `COVER_MAX_BYTES = 5 * 1024 * 1024` (5,242,880); `COVER_MAX_WIDTH = 1200`;
  - `type CoverImageType = "jpeg" | "png" | "webp"`; `type CoverRefusal = "tooLarge" | "wrongType"`;
  - `detectCoverImageType(bytes: Uint8Array): CoverImageType | null` — by first bytes only (§11): JPEG
    `FF D8 FF`; PNG `89 50 4E 47 0D 0A 1A 0A`; WebP `RIFF` at 0–3 and `WEBP` at 8–11; anything else `null`;
  - `prepareCoverImage(bytes: Uint8Array): Promise<{ ok: true; webp: Buffer; width: number; height: number } | { ok: false; refusal: CoverRefusal }>`
    — in order: `bytes.length > COVER_MAX_BYTES` → `tooLarge`; type `null` → `wrongType`; then `sharp`:
    apply the EXIF orientation (`autoOrient()`), `resize({ width: COVER_MAX_WIDTH, withoutEnlargement: true })`,
    `webp()`; a decode failure → `wrongType`. **Never** `withMetadata`, `keepMetadata`, `keepExif`,
    `withExif`, `keepIccProfile` or `keepXmp` here (§11: all metadata removed);
  - `coverObjectKey(bookTypeId: string): string` — throws `Error("invalid book type id")` unless the id
    matches `^[a-z0-9]+(-[a-z0-9]+)*$`; returns `book-types/<id>/<randomUUID()>.webp` (`node:crypto`).
