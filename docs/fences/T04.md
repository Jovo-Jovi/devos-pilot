#### Steps

- **S1 — Selector.** Create `src/content/notices.ts` exporting
  `selectPublishedNotices(notices: readonly LibraryNotice[]): LibraryNotice[]` and
  `selectLatestNotices(notices: readonly LibraryNotice[], limit: number): LibraryNotice[]`.
  `selectPublishedNotices` keeps only `status === "published"` and returns a **new** array ordered by
  `publishedOn` descending (string comparison is correct for `YYYY-MM-DD`), ties ordered by `id`
  ascending. It never mutates its input. `selectLatestNotices` is the first `limit` of that result
  (`limit` ≤ 0 → empty array). With the signed content the published ids are
  `reading-club-october, national-holiday-closure, new-arabic-arrivals`.
- **S2 — NoticeCard.** Create `src/components/NoticeCard.tsx`, a server component, no `"use client"`,
  no hook, no interface-text literal. Props: `locale: Locale`, `notice: LibraryNotice`,
  `headingLevel: "h2" | "h3"`. It renders an `<article className="notice-card">` holding the title
  for the locale in the given heading element, then `<p><Bidi>{notice.publishedOn}</Bidi></p>`
  (the date as a single text node inside `Bidi`), then the body for the locale in a `<p>`.
- **S3 — Home.** Edit `src/app/[locale]/page.tsx` (keep `await params` and `notFound()`). After the
  hours `<section>`, inside `<main>`, add a `<section>` with `h2` `section.latestNotices`, then
  either the latest 3 (`selectLatestNotices(libraryNotices, 3)`) as `NoticeCard`s with
  `headingLevel="h3"`, or, when that list is empty, `PendingState` with `state.pendingNotices`;
  then a `Link` (`next/link`) to `/${locale}/notices` with the text `link.allNotices`. Show the link
  in both cases. Do not change the header, hours or footer rendering.
- **S4 — Notices page.** Create `src/app/[locale]/notices/page.tsx`: await `params`, `notFound()`
  when `!isLocale(locale)`, then render `SiteHeader` (with `path="/notices"`), `<main>` holding an
  `h1` of `nav.notices`, then every published notice (`selectPublishedNotices(libraryNotices)`) as
  `NoticeCard` with `headingLevel="h2"`, one column, or `PendingState` with `state.pendingNotices`
  when none; then `SiteFooter`. No `generateStaticParams` is needed here: the `[locale]` layout
  provides it. Do not change `layout.tsx` or `global-not-found.tsx`. The route segment `notices` is
  the one permitted route exception (`docs/GLOSSARY.md` §3); name no other file, type or field with
  a forbidden bare noun.
- **S5 — Style.** Add rules to `src/styles/global.css` only. Tokens only, logical properties only,
  no raw colour or px value (a `1px` hairline is allowed). `.notice-card`: `background:
  var(--color-surface)`, `border: 1px solid var(--color-line)`, `border-radius: var(--radius-2)`,
  `padding: var(--space-4)`. Notices in one column with `gap: var(--space-5)`: wrap by styling
  `main` children only through a class you add on the notices page (for example
  `className="notice-list"` on a `<div>` that holds the cards, `display: flex; flex-direction:
  column; gap: var(--space-5)`). Use the same `notice-list` class on the home teaser's card list.
  Do not restyle anything else.
- **S6 — Unit tests.** Write `src/content/notices.test.ts`, one `it(` each: (a) the signed content
  selects exactly the three published ids in the order in S1; (b) a draft is never returned, even
  when it has the newest date; (c) two notices with the same `publishedOn` order by `id`; (d)
  `selectLatestNotices(..., 2)` returns the first two and `limit` 0 returns `[]`; (e) the input
  array is unchanged afterwards; (f) an input with no published notice returns `[]`. Test count
  over `src/**/*.test.ts` becomes 24 (after T03) + 6 = 30. State the arithmetic in the report.
- **S7 — Evidence.** Run `pnpm check`, then `node scripts/devos/probe.mjs --port 3100 / /ar /en /fr /ar/notices /en/notices`
  and the D3 command, and paste both outputs into the report.
