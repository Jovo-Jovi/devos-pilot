#### Steps

- **S1 — `headers()`.** In `next.config.ts` keep `cacheComponents`, `partialPrefetching`,
  `experimental.globalNotFound` and `redirects()` untouched, and add
  `async headers()` returning one entry: `source: "/:path*"`, with exactly the six headers and values
  from the table in `docs/SECURITY_MODEL.md` §2 (copy each value character for character from that
  file; do not paraphrase). Export the array so the test can read it: define
  `export const securityHeaders = [ { key, value }, ... ]` in `next.config.ts` and reuse it in
  `headers()`. No `includeSubDomains`, no `preload`, no `Cross-Origin-*` header, no extra header.
- **S2 — Test.** `src/security/headers.test.ts` imports `securityHeaders` and `default` from
  `../../next.config`, and asserts: (a) the key list equals the six names exactly (no more, no fewer),
  (b) each value equals the expected string written literally in the test, (c) `headers()` resolves
  to one entry whose `source` is `/:path*` and whose `headers` are `securityHeaders`, (d)
  `Strict-Transport-Security` does not contain `includeSubDomains`, (e) the CSP contains
  `frame-ancestors 'none'` and `form-action 'none'`. Test count over `src/**/*.test.ts` becomes
  4 (T01) + the number of `it(` cases you add; state the arithmetic in the report.
