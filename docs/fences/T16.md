### Prompt (canonical)

Staff at AAL2 list every `LibraryNotice` (drafts included), create one as a draft, edit it, publish
and unpublish it. Each write invalidates the cache tag `library-notices`, so `/ar`, `/en`,
`/ar/notices` and `/en/notices` show the change on the next request without a rebuild, while their
route-table symbol stays `○`. There is no delete (OD-10 §5). The browser never calls Supabase; every
write is a server action through `createStaffServerClient()`; RLS enforces the same rule again.

#### Steps

- **S1 — Input schema (`src/lib/supabase/library-notice-input.ts`, pure, no `server-only`).**
  - `pnpm add zod` (a runtime dependency). Only this file imports `zod`.
  - `parseLibraryNoticeInput(form: FormData)` returns `{ ok: true, value: LibraryNoticeInput }` or
    `{ ok: false, fields: Partial<Record<LibraryNoticeField, "required" | "date">> }`.
  - `LibraryNoticeInput = { publishedOn, titleAr, titleEn, bodyAr, bodyEn }` (strings, the
    `CONTENT_MODEL.md` §2 names). `LibraryNoticeField` is the union of those five names.
  - Mirror DATA_MODEL §2.1: each title and body is trimmed and must be non-empty (`btrim(…) <> ''`),
    else `"required"`. `publishedOn` must match `YYYY-MM-DD` and be a real calendar date (the column
    is `date`: `2026-02-30` fails), else `"date"`. A missing field is `"required"`.
  - `isLibraryNoticeId(value: string): boolean` uses the DATA_MODEL §2.1 kebab-case pattern.
  - `parseNoticeDone(value: unknown)` returns `"saved" | "published" | "unpublished"` or `null`.
- **S2 — Server actions (`src/app/[locale]/staff/notices/actions.ts`, `"use server"`).**
  - `createLibraryNotice(locale, previous, formData)`,
    `updateLibraryNotice(locale, id, previous, formData)`,
    `publishLibraryNotice(locale, id, formData)`, `unpublishLibraryNotice(locale, id, formData)`.
  - Each action, in this order: the locale check (as T14's `assertLocale`); `await requireStaff(locale)`
    (no session → sign-in, AAL1 → `/mfa`, no claim → refused); `isLibraryNoticeId(id)` (else
    `notFound()`); then the write.
  - Create inserts with `status: 'draft'` and no `id` (the column default), and reads back the new
    `id`. Update writes the five fields and keeps `status`. Publish sets `status` to `'published'`,
    unpublish to `'draft'`; neither changes another column. A write that errors or matches no row
    returns `{ error: "save" }`; a schema failure returns `{ error: "invalid", fields }`.
  - After a successful write only: `updateTag("library-notices")`, then redirect to
    `/{locale}/staff/notices/{id}?done=saved|published|unpublished`.
  - `LibraryNoticeFormState = { error: "invalid" | "save" | null; fields?: … }`. Never log a field
    value or an error body.
- **S3 — Pages (all: `StaffFrame` with the matching `path`, `Suspense`, `connection()` then
  `requireStaff(locale)` before any Supabase read).**
  - `/[locale]/staff/notices` — `h1` `staff.noticesTitle`; a link `staff.newNoticeTitle` to `new`;
    every row from `createStaffServerClient()`, ordered `published_on` desc then `id` asc, mapped with
    `libraryNoticesFromRows`. Each entry composes `ol.notices` / `li.notice`, `DateStamp`, the title
    in the page locale as `h2`, the status text (`staff.statusPublished` in `--color-open`,
    `staff.statusDraft` in `--color-ink-muted`) and a link `staff.editLink`. No body text.
  - `/[locale]/staff/notices/new` — `h1` `staff.newNoticeTitle`; the notice form, empty.
  - `/[locale]/staff/notices/[id]` — `h1` `staff.editNoticeTitle`. Invalid id or no row → `notFound()`.
    The form, prefilled; the status text; one secondary-button form: publish when draft, unpublish
    when published; `?done=` (via `parseNoticeDone`) shows `staff.confirmSaved|confirmPublished|confirmUnpublished`
    with `role="status"` in `--color-open`; a link `staff.backToNotices`.
  - The form (`src/app/[locale]/staff/NoticeForm.tsx`, client, `useActionState`, `noValidate`):
    `publishedOn` (`type="date"`), then `titleAr`, `titleEn`, `bodyAr`, `bodyEn` (titles `input`,
    bodies `textarea`), Arabic first; Arabic fields `dir="rtl"`, English `dir="ltr"`, no `lang`
    attribute. Each field: label above, hint below (`staff.publishedOnHint`, `staff.titleHint`,
    `staff.bodyHint`), and its error (`staff.errorRequired` or `staff.errorDate`) below the hint, all
    linked by `aria-describedby`. `staff.errorSave` at the top with `role="status"`. Submit
    `staff.saveSubmit`.
  - Staff home (`src/app/[locale]/staff/page.tsx`): add one link `staff.noticesLink` to
    `/{locale}/staff/notices` before the sign-out form (DESIGN_SYSTEM §9.1). Nothing else changes on
    T14/T15 pages.
  - Styles only in `staff.module.css`, with existing tokens and logical properties.
- **S4 — Catalogue.** Add exactly these 25 keys under `staff` in both catalogues (55 + 25 = 80 per
