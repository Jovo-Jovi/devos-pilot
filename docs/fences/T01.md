#### Steps

- **S1 — Scaffold outside the tree.** The repository root is not empty, so scaffold into the
  ignored folder `.devos/scaffold`:
  `pnpm create next-app@latest .devos/scaffold --ts --app --src-dir --eslint --no-tailwind --import-alias "@/*" --use-pnpm --yes --skip-install`
  (add `--disable-git` if the installed version supports it; if a nested `.git` appears in
  `.devos/scaffold`, delete it). Then copy into the root **only**: `package.json`,
  `pnpm-workspace.yaml`, `tsconfig.json`, `next.config.ts`, `eslint.config.mjs`, `AGENTS.md`
  (Next.js writes and re-adds it; committing it keeps the tree clean) and `src/`. Do **not** copy
  `README.md`, `.gitignore`, `public/`, `next-env.d.ts` or any lockfile. Append to the root
  `.gitignore` every line from the scaffold's `.gitignore` that is missing **except** `.env*` (the
  root already ignores env files and keeps `!.env.example`); keep existing lines untouched.
  Delete `.devos/scaffold`.
  If a flag is rejected by the current `create-next-app`, look up the replacement with Context7
  and record it in the report; HALT only if the replacement would add Tailwind.
- **S2 — package.json.** Set `"name": "devos-pilot"`, `"private": true`,
  `"engines": { "node": ">=20" }`. Scripts, exactly these names:
  ```
  "dev": "next dev",
  "build": "next build",
  "start": "next start",
  "lint": "eslint .",
  "typecheck": "tsc --noEmit",
  "test": "vitest run",
  "guards": "node scripts/guards/run-all.mjs",
  "check": "pnpm guards && pnpm typecheck && pnpm lint && pnpm test && pnpm build"
  ```
  Add dev dependency `vitest`. Run `pnpm install` so `pnpm-lock.yaml` is created and committed.
  ESLint must ignore `.devos/**`, `.next/**`, `scripts/**` and `node_modules/**`.
- **S3 — Vitest.** `vitest.config.ts`: `environment: "node"`, `include: ["src/**/*.test.ts"]`,
  alias `@` → `./src`.
- **S4 — Locale routing.** `src/i18n/config.ts` exports
  `export const locales = ["ar", "en"] as const;`, `export type Locale = (typeof locales)[number];`,
  `export const defaultLocale: Locale = "ar";`, `export function isLocale(v: string): v is Locale`,
  and `export function directionOf(l: Locale): "rtl" | "ltr"`.
  `src/app/[locale]/layout.tsx` is the **root layout**: `<html lang={locale} dir={directionOf(locale)}>`,
  `generateStaticParams()` returns both locales, and the layout and the page call `notFound()`
  when `!isLocale(locale)`. **Do not** export `dynamicParams`: it is not available while Cache
  Components is enabled (`node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/02-route-segment-config/dynamicParams.md`).
  Keep the scaffold's `next.config.ts` options (`cacheComponents`, `partialPrefetching`) and add
  `experimental: { globalNotFound: true }` plus `src/app/global-not-found.tsx`, which renders its
  own `<html>` with `lang={defaultLocale}` and `dir={directionOf(defaultLocale)}` (never a literal
  `lang`) and the catalogue's `site.productName` (see `.../file-conventions/not-found.md`, "multiple
  root layouts"). Remove the scaffold's `src/app/layout.tsx`, `src/app/page.tsx`. `/` redirects to
  `/ar` with a **non-permanent** redirect in `next.config.ts` `redirects()` (D-02). No middleware
  or proxy file, no `Accept-Language` reading.
- **S5 — Catalogues.** Create exactly these two files (byte content may be pretty-printed, keys and
