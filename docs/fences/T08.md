- **S2 — Pure placement module.** Create `src/content/timetable.ts` (imports only the
  `OpeningSlot` type from `./schema`) with these exports:
  ```ts
  export const TIMETABLE_START_HOUR = 8;
  export const TIMETABLE_END_HOUR = 22;
  export const TIMETABLE_TICK_HOURS = [8, 10, 12, 14, 16, 18, 20, 22] as const;
  export const TIMETABLE_DAY_ORDER = [6, 0, 1, 2, 3, 4, 5] as const; // Saturday → Friday
  export type BarPlacement = { start: number; size: number };
  export type TimetableDay = { dayOfWeek: number; slots: OpeningSlot[] };
  export function placeOnAxis(time: string): number;
  export function barPlacement(opensAt: string, closesAt: string): BarPlacement;
  export function timetableDays(slots: readonly OpeningSlot[]): TimetableDay[];
  ```
  - `placeOnAxis("HH:MM")` returns the position as a percentage of the 08:00–22:00 span:
    `(hours + minutes/60 − 8) / 14 × 100`, clamped to `0..100`, rounded to 4 decimals
    (`Math.round(x * 10000) / 10000`).
  - `barPlacement(opensAt, closesAt)` returns `start = placeOnAxis(opensAt)` and
    `size = round4(clampedEnd − clampedStart)` computed from the **unrounded, clamped** positions (not
    by subtracting two rounded values).
  - `timetableDays(slots)` returns exactly seven entries, one per value of `TIMETABLE_DAY_ORDER` in
    that order; each holds that day's slots sorted by `opensAt` ascending (string compare is correct
    for `HH:MM`); a day with none has `slots: []`. It never mutates its input.
  - Type and file names must pass `guard:naming` (no bare forbidden noun; `TimetableDay` and
    `BarPlacement` are fine, `Slot` alone is not).
