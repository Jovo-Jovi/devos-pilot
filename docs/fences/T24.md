  - `uploadBookTypeCover(locale: string, bookTypeId: string, previous: BookTypeCoverFormState, formData: FormData): Promise<BookTypeCoverFormState>`,
    in this order:
    1. `assertLocale` (as `hours/actions.ts`), then `await requireStaff(locale)`. Nothing reads the form before this.
    2. `bookTypeId` must be the `id` of a type in `(await readBookTypes()).bookTypes`, else `notFound()`.
    3. `formData.get("cover")`: if it is not a `File` or its size is 0, return `wrongType`. If it is over
       `COVER_MAX_BYTES`, return `tooLarge` before reading the bytes. Otherwise call `prepareCoverImage(bytes)`
       and return its refusal if it gives one.
    4. With `createStaffServerClient()`, read the current `object_key` for the type (`maybeSingle`). An error returns `save`.
    5. `coverObjectKey(bookTypeId)`, then `putCoverObject`. If the put fails, return `save`.
    6. `upsert({ book_type_id, object_key }, { onConflict: "book_type_id" })`, then `.select("book_type_id").maybeSingle()`.
       On an error or no row, delete the new object (ignore a failure there) and return `save`.
    7. If there was an old key, delete the old object. A failed delete is ignored: it leaves an orphan
       (`DATA_MODEL.md` §11).
    8. `updateTag("book-type-covers")`, then `redirect(\`/${locale}/staff/book-types?done=saved\`)`.
  - `removeBookTypeCover(locale: string, bookTypeId: string, formData: FormData): Promise<void>`: steps 1–2 as
    above. Then delete the link with `.delete().eq("book_type_id", id).select("object_key").maybeSingle()`. An error
    or no row redirects to `?error=save`. Then delete the object (a failure is ignored), call `updateTag`, and
    redirect to `?done=removed`.
